Project Description

My Fitness Guide is an iOS app built with SwiftUI for my CIS-137 midterm programming assignment. 
The app displays a list of fitness exercises, each with an image, name, and description.
The app uses a JSON file to store exercise information and SwiftUI navigation to display details for each selected exercise.

How to Use the App

1. Open the app to see the list of exercises.
2. Scroll through the list.
3. Tap an exercise to open its detail screen.
4. View the larger image, exercise name, and description.
5. Tap the back arrow to return to the main list.

Technologies Used

SwiftUI
