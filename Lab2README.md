Lab 2 - Flower Memory Game

Description

This project is a flower memory card layout created using SwiftUI for CIS-137 Lab 2.

The application displays 12 flower cards arranged in 3 columns and 4 rows. There are six pairs of flower images.

Users can tap individual cards to hide and reveal the flower images.

Features

Game title

12 flower cards

6 pairs of flowers

Interactive cards

SwiftUI @State property

Blue rounded card borders

How to Use

Open the application.

View the flower cards.

Tap a card to hide its flower.

Tap it again to reveal the flower.

Technologies Used

Swift

SwiftUI

Xcode
